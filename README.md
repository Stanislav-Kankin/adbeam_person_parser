# AdBeam Person Parser

Локальное Windows-приложение для обогащения выгрузок Контур.Продаж контактами
B2B. Единственный обязательный вход рабочего pipeline — Excel-выгрузка Контур,
а единственный ключ идентичности компании — валидный ИНН.

Внутренние файлы заказчиков не используются для автоматического сопоставления:
их структура непредсказуема, а названия, сайты и внешние ID не считаются
надёжной идентичностью. Числа из URL, ID ЕРЗ и другие похожие значения не
интерпретируются как ИНН.

## Что реализовано

- импорт `.xlsx`/`.xlsm` Контур.Продаж с обязательными колонками `Наименование`
  и `ИНН`;
- проверка контрольной суммы ИНН для юридических лиц и ИП;
- отклонение строк без валидного ИНН и пропуск повторных строк того же ИНН;
- типизированные сведения о компании, руководителе, каналах и источниках;
- безопасный обход официального сайта с учётом `robots.txt`, TLS, SSRF-защитой,
  таймаутами, лимитами и retry;
- извлечение company-scoped email, телефонов и публичных соцсетей;
- проверка покрытия выбранных ролей;
- SQLite checkpoint/resume и безопасная отмена между компаниями;
- атомарный Excel-экспорт в семь листов;
- Windows GUI и воспроизводимая PyInstaller-сборка.

Исходная книга читается без изменений. Итоговый файл нельзя сохранить поверх
входной выгрузки.

## Запуск программы

Запустите `dist\AdBeamPersonParser.exe`, затем:

1. Выберите выгрузку Контур.
2. Укажите новый итоговый файл `.xlsx`.
3. Выберите целевые роли.
4. Нажмите **Проверить вход** и убедитесь, что строки приняты по ИНН.
5. Нажмите **Запустить**.

В проверке показываются количество исходных и принятых строк, невалидные и
повторные ИНН, наличие сайтов, руководителей, email и телефонов. Строки без
валидного ИНН никогда не попадают в обработку.

Прогресс сохраняется в
`%LOCALAPPDATA%\AdBeamPersonParser\state\checkpoints.sqlite3`. Повторный запуск
той же выгрузки использует готовые результаты источников.

Итоговая книга содержит листы `Сводка`, `Компании`, `Контакты`, `Источники`,
`Журнал`, `Ручная очередь` и `Исходные данные`.

Текущая пилотная версия автоматически использует официальный сайт. Подключение
дополнительных разрешённых реестров, СМИ и бизнес-каталогов предусмотрено
архитектурой, но ещё не входит в рабочую сборку.

## Поддерживаемые колонки Контур

Обязательные:

- `Наименование`;
- `ИНН`.

Необязательные колонки распознаются по заголовкам Контур: КПП, ОГРН/ОГРНИП,
регион, статус, карточка в Фокусе, ФИО и должность руководителя, телефон, email,
сайт, виды деятельности, лицензии, финансовые показатели, сотрудники, филиалы,
источник и сегмент.

## Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m lead_enrichment.gui
```

Поддерживается Python 3.12 и новее.

## Сборка Windows EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\build_gui_exe.ps1
```

Скрипт создаёт `dist\AdBeamPersonParser.exe` и печатает размер и SHA-256.
Подробные архитектурные решения описаны в `ARCHITECTURE.md`.
