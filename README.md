# AdBeam Person Parser

Локальное Windows-приложение для обогащения выгрузок Контур.Продаж контактами
B2B. Архитектура и порядок разработки описаны в `ARCHITECTURE.md`.

Сейчас реализован первый инкремент: типизированные модели и импорт `.xlsx`
Контур.Продаж. Исходная книга читается без изменений; локальный путь и строки с
персональными данными не записываются в технические логи.

## Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
```

Поддерживается Python 3.12 и новее.
