# AdBeam Person Parser

Локальное Windows-приложение для обогащения выгрузок Контур.Продаж контактами
B2B. Архитектура и порядок разработки описаны в `ARCHITECTURE.md`.

Реализованы:

- типизированные модели и импорт `.xlsx` Контур.Продаж;
- импорт клиентского assessment для застройщиков по связанным листам
  `Ростовская область` и `ЛПР 2026 verified`, включая TIR, сайты, телефоны,
  первичных и альтернативных ЛПР;
- консервативное объединение assessment с Контуром по уникальному домену или
  нормализованному названию, с отдельным статусом для неоднозначных кандидатов;
- подготовка общей pipeline-карточки для бренда с ИНН или без него и проверка
  покрытия целевых ролей персональными и company-scoped каналами;
- оркестратор source-плагинов с SQLite checkpoint/resume, безопасной обработкой
  ошибок и удалением сохранённых данных компании;
- атомарный экспорт пилота в Excel с исходными полями, компаниями, контактами,
  evidence, журналом, ручной очередью и формульной сводкой;
- безопасный HTTP-клиент с TLS, SSRF-защитой, таймаутами, лимитами и retry;
- source-плагин обхода официального сайта с учётом `robots.txt`;
- извлечение company-scoped email, телефонов и публичных соцсетей;
- атомарный Excel-экспорт через проверенный временный файл и `os.replace`;
- тонкий Windows GUI с выбором файлов, предварительной проверкой входов,
  выбором целевых ролей, прогрессом и безопасной отменой между компаниями.

Исходная книга читается без изменений; локальный путь и строки с персональными
данными не записываются в технические логи. Внешние сайты в автоматических
тестах не вызываются.

Assessment может содержать только бренд без ИНН. До объединения с выгрузкой
Контур такая компания получает временный стабильный ключ по ID ЕРЗ, домену или
хешу нормализованных названия и региона. ИНН не угадывается из чисел в URL.

## Запуск пилота

Готовый локальный файл запускается двойным щелчком:

```text
dist\AdBeamPersonParser.exe
```

В окне приложения:

1. Выберите клиентский assessment `.xlsx` — это обязательный вход.
2. При наличии выберите результат Контур.Продаж `.xlsx`. Без него обработка
   продолжится по брендам и сайтам из assessment.
3. Укажите новый итоговый `.xlsx`, выберите целевые роли и нажмите
   **Проверить файлы**.
4. После проверки нажмите **Начать обработку**. Кнопка отмены завершает текущую
   компанию и сохраняет уже полученный частичный результат.

Приложение читает листы `Ростовская область` и `ЛПР 2026 verified`, объединяет
assessment с Контуром только при однозначном совпадении и обходит официальные
сайты. Итог содержит семь листов: исходные данные, компании, контакты,
доказательства, журнал, ручную очередь и сводку.

Текущая пилотная версия автоматически использует только официальные сайты.
Подключение дополнительных реестров, СМИ и бизнес-каталогов предусмотрено
архитектурой, но ещё не входит в рабочую сборку.

Состояние обработки хранится локально в
`%LOCALAPPDATA%\AdBeamPersonParser\state\checkpoints.sqlite3`, поэтому повторный
запуск того же набора входных файлов использует checkpoint.

## Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m lead_enrichment.gui
```

Поддерживается Python 3.12 и новее.

## Сборка Windows EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\build_gui_exe.ps1
```

Скрипт создаёт `dist\AdBeamPersonParser.exe` и печатает его размер и SHA-256.
